# MultiPlatformMSG

محصول جدید خدمتگزاران تک برای مدیریت ارتباط خصوصی چندکاناله، کمپین، Inbox تیمی، حساب‌های متصل و مدیریت‌شده، API، تعرفه و پایش زنده.

این مخزن در مرحله تحلیل و طراحی است و هنوز کدنویسی محصول آغاز نشده است.

## شروع اجباری برای عامل‌های هوش مصنوعی

همه عامل‌ها، بدون توجه به ابزار یا مدل، باید کار را از فایل زیر آغاز کنند:

`docs/ai/START_HERE.md`

هیچ عامل هوش مصنوعی اجازه ندارد بدون قرارداد مأموریت تأییدشده کدنویسی محصول را شروع کند.

## امنیت

قرار دادن Session پیام‌رسان، رمز، Token، فایل مخاطبان، دیتابیس، لاگ واقعی یا اطلاعات مشتری در این مخزن ممنوع است.
