# پذیرش UMAC-P v2

پروتکل قدیمی به‌عنوان منبع تاریخی حفظ می‌شود، اما اجرای پروژه براساس Governance نسخه ۲ انجام می‌شود. دلیل تغییر: جداسازی مدیر بدون کدنویسی، کدنویس محدود، بازبین بدون Patch، اسناد خرد، شناسه‌های پایدار، کنترل ماشینی محدوده و مصرف کمتر توکن.
