# فناوری پیشنهادی محصول

پیشنهاد فعلی: Next.js، NestJS، PostgreSQL، RabbitMQ، Redis، S3-compatible storage و Connector مستقل PHP/MadelineProto برای تلگرام. این تصمیم پیش از اولین کدنویسی باید همراه معماری ماژول‌ها و مدل استقرار تأیید شود.
