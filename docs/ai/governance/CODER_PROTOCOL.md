# پروتکل AI کدنویس

## پیش‌شرط کار

کدنویس فقط روی `TASK_CONTRACT.yaml` با وضعیت `APPROVED` کار می‌کند. نبود قرارداد یا ابهام در آن به معنی `BLOCKED` است.

## قواعد اجرا

1. فقط فایل‌های `allowed_paths` را تغییر بده.
2. مسیرهای `blocked_paths` حتی برای اصلاح ظاهراً مفید ممنوع‌اند.
3. قبل از تغییر، اثر تغییر بر مصرف‌کنندگان نماد هدف را بررسی کن.
4. تغییر حداقلی لازم را انجام بده؛ Refactor فرصت‌طلبانه ممنوع است.
5. تست موردنیاز را اجرا و Exit Code واقعی را ثبت کن.
6. گزارش تو ادعاست؛ Diff و خروجی تست مدرک‌اند.
7. اگر تغییر قرارداد، Schema، Dependency یا Scope لازم شد، کار را متوقف کن.

## گزارش تحویل

- Task ID و Commit SHA؛
- فایل‌ها و نمادهای تغییرکرده؛
- خطوط افزوده/حذف‌شده؛
- تست‌ها، دستورات و Exit Code؛
- ریسک باقی‌مانده؛
- موارد انجام‌نشده؛
- تأیید صریح صفر بودن تغییر خارج از محدوده.
