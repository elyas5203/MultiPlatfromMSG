# چرخه کمپین

## ساخت کمپین

1. مشتری فایل Excel یا CSV را وارد می‌کند.
2. سیستم ستون‌ها را تشخیص می‌دهد و کاربر تأیید می‌کند.
3. تکراری‌ها، منع تبلیغ، سابقه پیام و قابلیت ارسال بررسی می‌شوند.
4. مشتری متن و رسانه پشتیبانی‌شده کانال را می‌سازد و از هر ستون برای شخصی‌سازی استفاده می‌کند.
5. حداقل پنج نمونه واقعی پیش‌نمایش می‌شود.
6. سیستم هزینه، تعداد قابل ارسال و موارد کنارگذاشته‌شده را نشان می‌دهد.
7. مشتری زمان شروع را تعیین و کمپین را برای بررسی می‌فرستد.
8. مدیر خدمتگزاران تک محتوا و سیاست را بررسی می‌کند.

## بررسی محتوا

- مدیر می‌تواند پیشنهاد اصلاح بدهد؛ تغییر متن بدون اطلاع مشتری انجام نمی‌شود.
- در صورت رد یا عدم توافق، مشتری نسخه جدید ارسال می‌کند.
- محتوای سیاسی، ضدمذهبی، توهین‌آمیز، قمار، بزرگسال، جعل، فعالیت غیرقانونی و موارد ممنوع مشابه قابل ارسال نیست.
- API نیز همین بررسی‌ها و سیاست‌ها را طی می‌کند و راه دورزدن پنل نیست.

## اجرا

- ارسال تبلیغاتی در بازه امن پیش‌فرض انجام می‌شود و شب‌ها تا روز بعد متوقف می‌ماند؛ ساعت دقیق قابل تنظیم خواهد بود.
- سیستم فرستنده را خودکار و طبق سیاست انتخاب می‌کند.
- هر دریافت‌کننده دارای نتیجه مستقل و قابل ردیابی است.
- ارسال دوباره باید در برابر تکرار مقاوم باشد؛ Retry نباید پیام دوم یا هزینه دوم بسازد.

## توقف و پایان

- «توقف موقت» ارسال جدید را متوقف و باقی‌مانده را برای ادامه حفظ می‌کند.
- «ادامه» فقط باقی‌مانده مجاز همان کمپین را از سر می‌گیرد.
- «لغو کامل» باقی‌مانده را لغو و اعتبار رزروشده استفاده‌نشده را آزاد می‌کند.
- شروع کمپین جدید نباید صف کمپین متوقف‌شده را خودکار پاک یا ادامه دهد.
- توقف اضطراری سوپرادمین بر تمام شروع‌های جدید اولویت دارد.

## گزارش

هدف، پردازش‌شده، موفق، ناموفق، متوقف، لغوشده، حذف تکراری، منع تبلیغ، نوع فرستنده، هزینه رزرو و هزینه قطعی باید جدا گزارش شوند.
