# کانال‌ها، API و اتصال‌ها

## اولویت کانال‌ها

نسخه اول با تلگرام و بله شروع می‌شود. واتس‌اپ، ایتا، روبیکا، سروش و Instagram Direct بعداً با بررسی جداگانه اضافه می‌شوند. برای WhatsApp و Instagram مسیر رسمی اصل است.

## تلگرام

- اتصال حساب شخصی مشتری جزو نیاز محصول است، اما پرریسک و نیازمند Connector ایزوله و پایلوت است.
- حساب مدیریت‌شده نیز بدون دسترسی ورود مشتری پشتیبانی می‌شود.
- متن و رسانه، Inbox و وضعیت حساب لازم‌اند.
- عدد ثابت مانند «روزانه ۱۰ پیام امن» قانون محصول نیست؛ ظرفیت باید از وضعیت واقعی و سیاست مصوب بیاید.

## بله

مسیر رسمی سفیر/Bot API انتخاب اولیه است. قابلیت‌های ارسال، دریافت پاسخ، رسانه و محدودیت‌ها باید در پایلوت واقعی اثبات شوند. اتصال غیررسمی حساب شخصی بله تا زمان تصمیم مستند، جزو تعهد نسخه اول نیست.

## API و اتصال سرویس‌ها

- مشتری می‌تواند از API محصول استفاده کند، اما API تمام کنترل‌های اعتبار، رضایت، تأیید کمپین و محدودیت کانال را رعایت می‌کند.
- Webhook خروجی باید امضاشده، قابل Retry و مقاوم در برابر تکرار باشد.
- اتصال گفتینو و حداقل یک سامانه پیامکی در نسخه اول پیش‌بینی می‌شود.
- کلیدها و Sessionها در رابط یا لاگ نمایش داده نمی‌شوند.
- هر Connector باید بتواند بدون ازکارانداختن هسته محصول متوقف یا جایگزین شود.
