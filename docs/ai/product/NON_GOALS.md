# موارد خارج از محدوده یا ممنوع

- مزرعه حساب و تولید انبوه حساب؛
- دورزدن محدودیت پیام‌رسان‌ها؛
- تضمین بن‌نشدن یا ارسال نامحدود؛
- اتصال تجاری حساب شخصی بله بدون API یا مجوز رسمی؛
- ارسال سرد بدون Policy و کنترل توقف؛
- AI پاسخ‌گوی خودکار در نسخه اول؛
- White-label کامل در نسخه اول؛
- اپلیکیشن Native جدا در نسخه اول؛
- Kubernetes و Microservice کامل در شروع؛
- اشتراک خودکار اطلاعات تجاری سازمان‌های نامرتبط؛
- استفاده از پروژه قدیمی به‌عنوان هسته اجرایی محصول جدید.
