# سازمان‌ها، برندها و سطح دسترسی

## تصمیم‌های قطعی

- محصول چندسازمانی است و اطلاعات هر سازمان باید کاملاً از دیگران جدا بماند.
- یک سازمان می‌تواند چند برند، تیم و کارمند داشته باشد.
- بعضی مخاطبان و منابع می‌توانند بین برندهای همان سازمان مشترک باشند؛ این اشتراک باید صریح و قابل کنترل باشد.
- امکان اشتراک بعضی منابع یا قراردادها میان چند سازمان مدنظر است، اما نباید باعث مشاهده ناخواسته اطلاعات یکدیگر شود.
- سلسله‌مراتب شامل سوپرادمین خدمتگزاران تک، مدیران عملیاتی، مدیر سازمان مشتری و کارمندان سازمان است.
- مدیر سازمان مشتری خودش کارمندانش را دعوت و حذف می‌کند.
- کارمند می‌تواند عضو چند تیم، مانند فروش و پشتیبانی، باشد.
- انتقال گفتگو میان کارمندان مجاز است و برای ساده‌ماندن رابط، در نسخه اول محدودیت ریز برای انتقال لازم نیست.
- حذف کارمند فوراً دسترسی او را قطع می‌کند؛ سوابق با نام او می‌ماند و گفتگوهای بازش «بدون مسئول» می‌شوند.
- خدمتگزاران تک امکان نظارت مدیریتی بر کمپین‌ها، محتوا، حساب‌های مدیریت‌شده و گفتگوها را دارد؛ این دسترسی باید ثبت رویداد شود.

## قواعد غیرقابل‌مذاکره

- هیچ نقش یا API نباید مرز سازمان را دور بزند.
- هر عملیات حساس باید هویت اقدام‌کننده، زمان و سازمان را ثبت کند.
- اشتراک منبع با اشتراک داده مشتری یکی نیست؛ دسترسی‌ها باید جدا تعریف شوند.
- سوپرادمین بودن مجوز تغییر بی‌ردپای داده مالی یا پیام‌ها نیست.
