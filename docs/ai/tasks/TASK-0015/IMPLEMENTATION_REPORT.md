- **AC-01 (مهاجرت دیتابیس و هش رمز):** فیلدهای `username`, `password_hash`, `failed_login_attempts`, `locked_until` به جدول `staff` اضافه شدند. قید یکتایی مرکب `(tenant_id, username)` ایجاد شد. جدول `sessions` با کلید خارجی مرکب دیتابیس `FOREIGN KEY ("tenant_id", "staff_id") REFERENCES "staff"("tenant_id", "id") ON DELETE CASCADE` پیاده شد. رمز خام ذخیره نمی‌شود و توکن‌ها با هش SHA-256 ذخیره می‌شوند.
